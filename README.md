# Enterprise Lead-to-Cash Automation Suite 🚀

Automated B2B lead qualification, territory assignment, and opportunity-to-quote governance using native Salesforce declarative tools.

## 📌 Project Overview
Designed to eliminate manual sales bottlenecks by orchestrating an end-to-end Lead-to-Cash lifecycle within Salesforce Sales Cloud. The system automatically routes incoming web leads based on company size and geographic territory, triggers automated task assignment for sales reps, and enforces approval workflows for high-discount quotes.

## 🛠️ Core Salesforce Components Built
- **Declarative Automation:** Built Record-Triggered Flows and Screen Flows to handle lead assignment logic and guided opportunity creation.
- **Approval Processes:** Configured multi-tier approval routing for quotes exceeding a 15% discount threshold.
- **Data Governance:** Implemented strict Validation Rules (`Prevent_Closed_Won_Without_Contract`, `Mandatory_Billing_Address`) to ensure data integrity.
- **Reporting & Dashboards:** Created real-time sales pipeline visibility dashboards tracking conversion rates and rep activity metrics.

## 📂 What This Project Demonstrates
- Translating complex business requirements into point-and-click Salesforce automation.
- Deep understanding of Sales Cloud data models (Leads -> Accounts, Contacts, Opportunities).
- Ensuring data quality using validation rules and strict user permissions.
